## 結論：Fintokei攻略の核は「利益を狙うこと」ではなく「退場しないこと」

Fintokei（フィントケイ）のチャレンジ攻略を一言でまとめると、次の通りです。

> **攻略の主役は利益目標ではなく、最大損失ルールである。1日損失5%・トータル損失10%に一度も触れないことを最優先し、利益はそのルールの内側で「積み上がってしまう」状態を作る。利益を取りにいくほど落ちやすく、守りを固めるほど合格に近づく——これがFintokei攻略の逆説です。**

多くの不合格者は「Phase1の利益目標10%をどう達成するか」から考え始めます。しかし正しい順序は逆です。先に守るべき損失ラインを引き、その内側でしか動かないルールを自分に課す。すると利益は副産物として積み上がっていきます。本記事では、TheStandard（2-Step）とTheInstantそれぞれの戦い方、ロット計算、やってはいけないNG行動、EA活用まで、突破確率を上げる手順を実践目線で解説します。

まず攻略ポイントを早見表で押さえておきましょう。

| 攻略ポイント | 守るべき基準 | ひとことコメント |
|---|---|---|
| 1日の許容損失 | 5%の半分（2.5%）で自主ストップ | ルール上限ではなく自主上限で止める |
| 1トレードのリスク | 口座資金の0.5〜1% | $50kなら$250〜$500/回 |
| 連敗時の対応 | その日は手仕舞い | 取り返しトレードが最大の敵 |
| 利益ペース | 1日1〜2%で十分 | 期限なしなので焦らない |
| エントリー回数 | 1日2〜3回まで | 多すぎる手数はルール抵触の温床 |
| 指標発表時 | 原則ノーポジ | 急変動は1日損失ルールに直結 |

## 30秒でわかる：Fintokei攻略の基本方針

**Fintokei攻略の基本方針とは、「最大損失ルールから逆算してロットと許容損失を固定し、利益目標は守りの内側で自然に到達させる」という考え方です。** チャレンジに落ちる人の大半は、トレード手法そのものが悪いのではなく、1回のロットが大きすぎたり、負けを取り返そうとして1日損失ルールに触れたりして「自滅」しています。攻略とは、勝率の高い必勝法を探すことではなく、自滅する要因を一つずつ消していく作業です。

Fintokeiのチャレンジには、主に2つのプランがあります。

- **TheStandard（2-Step）**：Phase1で利益目標10%、Phase2で5%を達成する2段階の評価試験。1日最大損失5%、最大トータル損失10%、期限なし。合格後の資金口座でのプロフィットスプリットは80%。
- **TheInstant（$50k）**：評価試験なしで即時に資金口座を運用できるプラン。1日最大損失4%、トータル6%、スプリット60%、返金なし。

どちらも**期限なし**（TheStandard）で日数に追われないこと、**EA可・スキャル可・指標トレード可・両建て可・週末保有可・スワップフリー**と取引制限が緩いこと、**MT4/MT5/DXtrade**に対応し**日本語完全対応**であることが攻略上の追い風になります。母体は2014年から続くブローカー Purple Trading です。基本スペックや評判の詳細は <a href='/prop/fintokei/'>Fintokeiの詳細ページ</a> と <a href='/guide/fintokei-hyoban/'>Fintokeiの評判記事</a> も併せて確認してください。

> **【宮城ガイの監修コメント】** 攻略記事という言葉を聞くと「裏技」を期待する人が多いのですが、プロップファームに裏技は存在しません。私が見てきた合格者に共通するのは、例外なく「派手な勝ち方をしていない」こと。1日1%を淡々と積む人が、結局いちばん早くゴールしています。地味さこそ最大の攻略法だと思ってください。

## 攻略ステップ：Phase1→Phase2→資金口座

Fintokeiの2-Stepは、フェーズごとに「求められること」と「最適な戦い方」が変わります。同じ手法を全フェーズで使うのではなく、フェーズの性質に合わせてギアを変えるのが攻略の要です。

### Phase1：利益目標10%（評価試験の第一関門）

Phase1の目標は利益10%、守るべきは1日損失5%・トータル損失10%です。ここで意識すべきは「**目標10%を1回で取りにいかない**」ことです。

- **1日の利益目標は1〜2%に分割する**：10%を10〜20営業日に分けて積み上げる発想。期限がないため、急ぐ理由がありません。
- **1日損失の自主ストップを2.5%に設定する**：ルール上限は5%ですが、ここに到達してから止まるのでは遅すぎます。半分の2.5%に達したらその日は手仕舞い、と決めておくと、ルール違反の事故がほぼ消えます。
- **得意な相場だけで戦う**：Phase1は「いける時だけ参加する」が正解。ノーポジでいる勇気が合格率を上げます。

利益目標達成の考え方は <a href='/guide/propfirm-goukakuritsu/'>プロップファームの合格率を上げる方法</a> でも詳しく扱っています。

### Phase2：利益目標5%（守りを固める第二関門）

Phase2は目標が5%に下がり、ルール（1日5%・トータル10%）は据え置きです。目標が半分になるため、攻略の主眼は「攻める」から「**守りきる**」へ完全にシフトします。

- **ロットをPhase1より下げてもよい**：目標が5%なら、より小さいロットで時間をかけて積めば十分。リスクを取る理由が薄いフェーズです。
- **連勝に乗らない**：Phase2で多いのが「Phase1を勢いで抜けたまま大きく張って自滅」するパターン。ここでは1トレードのリスクをむしろ絞ります。
- **5%に到達したら即終了**：あと少し伸ばそう、はPhase2の禁句。目標タッチで潔く完了させます。

2ステップ全体の流れと各段階の注意点は <a href='/guide/propfirm-step/'>2ステップチャレンジの進め方</a> にまとめています。

### 資金口座（合格後の本番運用）

Phase1・Phase2を抜けると、いよいよ資金口座での本番運用です。TheStandardのスプリットは80%。ここで重要なのは「**合格した時のルールを変えない**」ことです。

- **合格した手法・ロットをそのまま継続する**：本番だからと急に大きく張ると、資金口座でも1日損失ルールは適用されるため、せっかくの口座を失いかねません。
- **出金を意識しすぎない**：早く稼ごうとするほどロットが膨らみます。資金口座こそ「守りの運用」を続けるのが長く稼ぐ道です。

各フェーズに共通する攻略の小技は <a href='/guide/propfirm-challenge-tips/'>チャレンジ攻略のコツ</a> も参考にしてください。

## 守るべきリスク管理ルール

ここがFintokei攻略の心臓部です。TheStandardの規則は「1日最大損失5%」「最大トータル損失10%」。この2つの数字に**絶対に触れない設計**を、トレードを始める前に作り込みます。

### 自主ルールはレギュレーションの「半分」に置く

ルール上限ギリギリで運用すると、1回の想定外で即アウトです。攻略のセオリーは、自主上限を公式ルールの半分に置くこと。

| 項目 | Fintokeiの公式ルール | 攻略のための自主上限 |
|---|---|---|
| 1日の損失 | 5%まで | 2.5%で手仕舞い |
| トータル損失 | 10%まで | 5%到達でロット半減・見直し |
| 1トレードのリスク | （規定なし） | 0.5〜1% |

公式ルールが「触れたら即失格のライン」であるのに対し、自主上限は「ここで一度立ち止まって冷静になるライン」です。この緩衝地帯があるかどうかで、合格率は大きく変わります。ドローダウンの仕組みそのものは <a href='/guide/propfirm-drawdown/'>プロップファームのドローダウン解説</a> で詳しく確認できます。

### ロット計算：損切り幅から逆算する

ロットは「なんとなく」で決めてはいけません。**1トレードの許容損失額 ÷ 損切り幅（pips）÷ 1pipの価値** で逆算します。

例：$50k口座、1トレードのリスクを1%（=$500）、損切り20pipsで運用する場合
- ドル円1ロット（10万通貨）の1pip = 約$10（=約1,000円相当）
- 許容損失$500 ÷ 20pips = 25pipsあたり… ではなく、$500 ÷ (20pips × $10) = 約2.5ロット相当

つまり損切りを浅く取れる相場ほどロットを上げられ、損切りが深くなる相場ではロットを自動的に下げる、という規律になります。「ロットを固定して損切り幅を変える」のは逆で、攻略上は危険です。具体的な計算式とテンプレートは <a href='/guide/propfirm-lot/'>プロップファームのロット計算</a> にまとめています。

> **【宮城ガイの監修コメント】** ロット計算を「面倒だから感覚で」とやる人ほど落ちます。逆に言えば、エントリーのたびに電卓を叩く一手間を惜しまないだけで、上位数十%に入れてしまう世界です。私は今でも全トレードでロットを計算してからエントリーします。これは熟練しても省略しない、攻略の絶対作業だと考えてください。

### TheInstantはさらに厳格に

TheInstant（$50k）は1日損失4%・トータル6%とTheStandardよりタイト、かつスプリット60%・返金なしです。評価試験がない代わりに、最初から本番の資金口座と同じ緊張感が要求されます。自主上限は1日2%・トータル3%程度に置き、ロットもTheStandardより一段絞るのが攻略の前提です。

## やってはいけないNG行動

不合格の原因は、手法の優劣よりも「やってはいけないこと」をやってしまうことに集中しています。逆に言えば、以下を全部やめるだけで合格確率は跳ね上がります。

### NG1：過大ロットで一発を狙う

最も多い失格原因です。「早く目標に届かせたい」という焦りから、口座資金の数%を1トレードに賭けてしまう。1回の含み損で1日損失5%に到達し、その日のうちに退場します。期限がないFintokeiでは、急ぐ理由はゼロ。リスクは常に1%以内に固定してください。

### NG2：負けを取り返そうとする（リベンジトレード）

連敗した直後にロットを上げて取り返しにいく——これは攻略上の最大の敵です。負けた直後は判断が歪んでおり、勝率が下がっているのにロットだけ上がる最悪の状態。**「その日2.5%負けたら、勝っていてもいなくても手仕舞い」**を機械的に守ることで、リベンジトレードは構造的に封じられます。

### NG3：経済指標で一発逆転を狙う

Fintokeiは指標トレードを禁止していませんが、攻略の観点では別問題です。重要指標の発表直後はスプレッドが開き、価格が一瞬で大きく飛びます。損切り注文が想定価格で約定せず、1日損失ルールを一気に突破するリスクがあります。攻略中は原則ノーポジが無難です。指標を扱う際の注意点は <a href='/guide/propfirm-news/'>プロップファームと経済指標トレード</a> を確認してください。

### NG4：手数を増やしすぎる

「チャンスを逃したくない」と1日に何度もエントリーすると、その分だけルール抵触の機会が増えます。1日2〜3回までと決め、見送る勇気を持つこと。スキャルピング自体はFintokeiで認められていますが、回数管理を怠ると同じ罠にはまります。スキャル運用の注意は <a href='/guide/propfirm-scalping/'>プロップファームでのスキャルピング</a> も参考になります。

### NG5：合格後にルールを変える

資金口座に入った途端、気が緩んでロットを上げる人がいます。資金口座にも1日損失・トータル損失ルールは適用されます。合格した時のロットと規律をそのまま続けることが、長く稼ぐための攻略法です。

## EA・自動売買を使う場合の攻略

FintokeiはEA（自動売買）の使用を認めています。手動トレードの感情リスクを排除できる点で、攻略との相性は良好です。ただし「EAを動かせば勝手に合格する」わけではありません。

- **ドローダウン規則はEAにも同じく適用される**：EAのロジックが1日損失5%・トータル10%に抵触しない設計かを必ず確認します。特にナンピン・マーチンゲール系（負けたらロットを増やす）は、一度のトレンドで1日損失ルールを一瞬で突破するため危険です。
- **ロット設定をルールから逆算する**：EAのデフォルトロットは口座資金を考慮していないことが多いため、前述のロット計算に合わせて手動で絞ります。
- **稼働前にデモ・小ロットで検証する**：本番投入の前に、最大ドローダウンが自主上限（1日2.5%・トータル5%）の内側に収まるかを確認します。
- **指標時は自動停止させる**：可能であれば、重要指標の前後でEAを止める設定にすると、NG3のリスクを自動的に回避できます。

EAは「規律を機械化する道具」として使えば強力ですが、「丸投げで楽をする道具」として使うと最大損失ルールで落ちます。EA運用の全体像は <a href='/guide/propfirm-ea/'>プロップファームでのEA利用</a> で解説しています。

> **【宮城ガイの監修コメント】** EAを使う人ほど「動かしっぱなし」になりがちですが、私は資金口座を任せられるEAほど、運用者が毎日ドローダウンを目視チェックしているものだと考えています。自動化しても、見るのをやめてはいけません。EAは規律を代行してくれますが、ルール抵触の最終責任はあくまでトレーダー本人にあります。

## まとめ

Fintokei攻略の本質は、繰り返しになりますが「利益を狙うこと」ではなく「退場しないこと」にあります。最後に攻略の要点を整理します。

- **最大損失ルールから逆算する**：1日5%・トータル10%（TheStandard）に触れない設計を、トレード前に作り込む。
- **自主上限は公式ルールの半分**：1日2.5%で手仕舞い、トータル5%でロット見直し。緩衝地帯が事故を防ぐ。
- **ロットは損切り幅から逆算**：1トレードのリスクは口座資金の0.5〜1%に固定する。
- **フェーズで戦い方を変える**：Phase1は得意相場で積む、Phase2は守りきる、資金口座はルールを変えない。
- **NG行動を全部やめる**：過大ロット・リベンジ・指標ギャンブル・手数過多・合格後の油断。
- **EAは規律の機械化として使う**：ドローダウン規則はEAにも適用される。丸投げにしない。

期限がなく取引制限も緩いFintokeiは、焦らず守りを固めれば実力を出しやすい環境です。まずは <a href='/prop/fintokei/'>Fintokeiの詳細ページ</a> でプランを確認し、<a href='/guide/fintokei-hyoban/'>評判記事</a> で全体像を掴んでから挑戦を組み立ててください。他社との比較を踏まえて選びたい場合は <a href='/guide/propfirm-osusume/'>おすすめプロップファーム比較</a> も参考になります。

なお、本記事は公開情報をもとにした攻略の考え方であり、合格や利益を保証するものではありません。最終的なルールは必ずFintokei公式の最新規約を確認のうえ、ご自身の判断で運用してください。
