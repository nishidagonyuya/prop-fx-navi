## 結論：まずTheStandard $100kが万人向け、最短で始めたいならTheInstant

Fintokei（フィントケイ）のプラン選びを一言でまとめると、次の通りです。

> **試験を経て高スプリット（80%）を狙うなら「TheStandard $100k」が標準解。試験を飛ばして最短で資金を使いたいなら「TheInstant $50k」。資金規模を一気に上げたい上級者は「TheStandard $200k」。**

## 30秒でわかる：Fintokeiのプラン構成

**Fintokeiのプランは、評価試験に合格してから資金を得る「TheStandard（2段階チャレンジ）」と、試験を飛ばしていきなり資金を使える「TheInstant（即時資金型）」の2系統で構成されています。** 前者は手取り（スプリット）が高く返金もある代わりに合格というハードルがあり、後者は手軽な代わりにスプリットと許容損失が控えめ、という対照的な設計です。

Fintokeiはチェコの正規ブローカーPurple Trading（2014年〜・プラハ）を母体に2023年に設立され、累計支払額は$50M+。サイト・規約・サポートまで完全日本語対応で、日本人がプラン内容を母国語で精査できる数少ないプロップです。日本語で完結できる業者をまとめて見たい方は [日本語対応プロップファーム](/guide/propfirm-japanese/) も参考になります。プロップ全体の中での立ち位置は [おすすめプロップファームランキング](/guide/propfirm-osusume/) で確認できます。

そもそもプラン選びの前提として、プロップファーム共通の仕組み—特に「ドローダウン（許容損失）」と「プロフィットスプリット（利益分配率）」—の理解は欠かせません。用語に不安がある方は [プロップファームのドローダウン解説](/guide/propfirm-drawdown/) を先に押さえておくと、以降の数字が一気に読みやすくなります。

### プラン選びで見るべき5つの軸

Fintokeiに限らず、プロップのプランは次の5要素で性格が決まります。この順番で評価すると、見た目の派手さに惑わされず本質を比較できます。

1. **受験料**：入口で支払うコスト。返金の有無も込みで考える
2. **口座サイズ**：取引できる資金枠。大きいほど同じ率でも利益額・損失額が増える
3. **利益目標**：合格に必要な利益率。試験型のみに存在する
4. **ドローダウン（許容損失）**：1日あたり・トータルの2種類。退場ラインを決める最重要項目
5. **プロフィットスプリット**：稼いだ利益のうち自分が受け取れる割合。長期の手取りを左右する

このうち、初心者が軽視しがちなのが4の「ドローダウン」と5の「スプリット」です。受験料や口座サイズは目に入りやすい一方、許容損失と分配率は数字が地味で見落とされがち。しかし実際に資金を守り、手取りを増やすのはこの2つです。Fintokeiの3プランも、まさにこの軸の組み合わせで個性が分かれています。

## 各プランの詳細

ここからは3プランを1つずつ分解します。共通して期限なし（時間制限なし）で進められるのがFintokeiの特徴で、「○日以内に目標達成」という時間プレッシャーがない分、無理なロットを張らずに済むのは大きな利点です。

### TheStandard $100k：標準の2段階チャレンジ

| 項目 | 内容 |
|---|---|
| 口座サイズ | $100,000 |
| 受験料 | $599 |
| Phase1 利益目標 | 10% |
| Phase2 利益目標 | 5% |
| 1日最大損失 | 5% |
| 最大トータル損失 | 10% |
| プロフィットスプリット | 80% |
| 受験料返金 | あり |
| 期限 | なし |

Fintokeiの「標準型」にあたるプランです。Phase1で口座残高に対して10%の利益を出し、Phase2でさらに5%を達成すると本番資金（ファンド）口座に移行できます。利益分配は80%と業界平均水準で、受験料$599は所定条件を満たせば返金される設計です。

注目すべきは許容損失で、1日あたり最大5%・トータルでも最大10%まで許されます。$100,000口座なら1日$5,000・累計$10,000がストップラインの目安です。期限がないため、利益目標15%（Phase1+Phase2合計）を、自分のペースで余裕を持って積み上げられます。

具体的なイメージをつかむために、合格後の手取りを試算してみましょう。本番口座$100,000で月に5%（$5,000）の利益を出したとします。スプリット80%なら、そのうち$4,000が自分の取り分です。仮に同じ利益を毎月安定して出せれば、年間では相当の金額になります。もちろん相場は思い通りに動きませんが、「80%という分配率がどれだけ効くか」を金額で実感しておくと、プラン選びの判断がぶれません。

また、Phase1（利益目標10%）とPhase2（利益目標5%）は段階を分けて評価される仕組みです。Phase1で勢いよく稼いでも、Phase2で気が緩んでドローダウンに引っかかれば振り出しに戻ります。期限がないからこそ「2段階を通して規律を保てるか」が問われる—これがTheStandardの本質です。逆に言えば、時間に追われず腰を据えて取り組めるトレーダーにとっては、これ以上ない練習台にもなります。

初挑戦でFintokeiを試すなら、まずこのプランが基準点になります。なぜ$100kが「ちょうどよい」のかは、後述の「どのプランを選ぶべきか」で詳しく触れます。

### TheStandard $200k：資金規模を一気に上げたい上級者向け

| 項目 | 内容 |
|---|---|
| 口座サイズ | $200,000 |
| 受験料 | $1,099 |
| Phase1 利益目標 | 10% |
| Phase2 利益目標 | 5% |
| 1日最大損失 | 5% |
| 最大トータル損失 | 10% |
| プロフィットスプリット | 80% |
| 受験料返金 | あり |
| 期限 | なし |

ルール構造はTheStandard $100kとまったく同じで、口座サイズが$200,000に倍増したバージョンです。利益目標（Phase1:10%・Phase2:5%）もドローダウン（1日5%・トータル10%）も率は同一なので、考え方は$100kの延長線上にあります。

違いは「金額のスケール」です。同じ10%でも$100kなら利益目標$10,000、$200kなら$20,000。許容損失も1日$10,000・トータル$20,000と倍になります。率が同じということは、必要なロットや1トレードあたりの値幅も実質的にスケールアップするということ。資金管理の精度がそのまま結果に直結します。

ここで見落としがちなのが「金額が大きくなると判断が鈍る」という心理的な落とし穴です。$100kで$1,000の含み損なら冷静に切れた人が、$200kで$2,000の含み損になると「もう少し戻るかも」と損切りをためらう—これは多くのトレーダーが経験する罠です。率が同じでも、目に映る金額のインパクトはまったく違います。$200kを選ぶなら、金額ではなく率（口座に対する何%か）でリスクを管理する習慣が必須になります。

逆に言えば、すでに$100kでこの「金額の心理」を克服できている人にとって、$200kは単純に取り分が増える魅力的な選択肢です。スプリット80%で利益額が倍になれば、手取りも比例して大きくなります。実力と金額耐性が伴っているかどうか—ここが$200kを選ぶか否かの分水嶺です。

受験料$1,099は$100kの約2倍ですが、返金制度がある点は同じです。すでに$100kクラスで安定して合格・運用できる実力があり、より大きな資金枠で同じ手法を回したいトレーダー向けのプランと位置づけられます。

> **【宮城ガイの監修コメント】** $200kは「上級者向け」という言葉に尽きます。率が同じでも、扱う金額が倍になると心理的なプレッシャーは想像以上に重くのしかかります。$100kで一度も冷静さを失わずに目標達成できた人だけが、次のステップとして検討すべきプランです。いきなり$200kから入るのは、私はおすすめしません。

### TheInstant $50k：試験なしで即スタートできる即時資金型

| 項目 | 内容 |
|---|---|
| 口座サイズ | $50,000 |
| 受験料 | $549 |
| 利益目標 | なし（Instant Funding／即時資金） |
| 1日最大損失 | 4% |
| 最大トータル損失 | 6% |
| プロフィットスプリット | 60% |
| 受験料返金 | なし |
| 期限 | なし |

TheStandardとは設計思想が異なる「即時資金型（Instant Funding）」のプランです。最大の特徴は、評価試験（チャレンジ）が不要なこと。申込後すぐに$50,000の資金口座でトレードを始められ、Phase1・Phase2のような利益目標をクリアする工程がありません。

その代わり、条件はTheStandardよりタイトに設定されています。プロフィットスプリットは60%（TheStandardは80%）、許容損失も1日4%・トータル6%とやや厳しめ。$50,000口座なら1日$2,000・累計$3,000がストップラインです。受験料$549の返金もありません。

「試験のプレッシャーが苦手」「とにかく早く実弾で結果を出したい」という人に刺さる一方、手取りの薄さと許容損失の狭さは正しく理解しておく必要があります。即時資金型は各社で条件差が大きいジャンルなので、Fintokei単体で決める前に [即時資金型プロップ徹底比較](/guide/propfirm-instant/) で他社水準と見比べることを強くおすすめします。

ここで、TheStandard $100kとTheInstant $50kを並べて手取り感覚を比べてみます。同じ$3,000の利益を出した場合、TheStandard（スプリット80%）なら$2,400、TheInstant（スプリット60%）なら$1,800。差は$600です。利益が大きくなるほどこの差は開いていきます。試験という工程を省いた手軽さの「対価」が、ここに表れていると考えると分かりやすいでしょう。

加えて、TheInstantは許容損失が1日4%・トータル6%とTheStandardより狭く設定されています。$50,000口座なら1日$2,000の損失でストップラインに近づく計算です。回転数の多いトレードや、含み損を抱えやすいスタイルだと、この狭さがボディブローのように効いてきます。「試験がない＝簡単」ではなく、「試験がない代わりに日々の規律がより厳しく問われる」と捉えるのが正確です。

## どのプランを選ぶべきか

3プランの数字を並べても、「で、自分はどれ？」が一番知りたいところでしょう。タイプ別に整理します。判断に迷ったら、まず「試験を受けられる時間と精神的余裕があるか」を自分に問うてください。あるならTheStandard、ないならTheInstant、という大きな分岐がまず立ちます。そのうえで資金規模やスタイルで詰めていくと、迷いが減ります。

### 初心者・Fintokeiが初めての人 → TheStandard $100k

プロップ自体が初挑戦、もしくはFintokeiを初めて使う人は、まず **TheStandard $100k** が無難です。理由は3つあります。

1. 受験料$599が返金対象で、合格すれば実質コストを抑えられる
2. スプリット80%と手取りが高く、合格後の旨味が大きい
3. 期限なしのため、Phase1の10%を焦らず積める

$50kのTheInstantは一見ハードルが低く見えますが、スプリット60%・許容損失の狭さ・返金なしという条件は、慣れていない人ほど効いてきます。「まず仕組みに慣れる」段階では、王道の2段階チャレンジで型を身につけるほうが結果的に近道です。合格率を上げる立ち回りは [チャレンジ攻略のコツ](/guide/propfirm-challenge-tips/) を必ず読んでおきましょう。

### とにかく最短で取引を始めたい人 → TheInstant $50k

「試験のための時間や精神的負荷をかけたくない」「数日でも早く実資金を触りたい」というニーズには **TheInstant $50k** が合います。試験なしで即スタートできる手軽さは、他にない価値です。

ただし、スプリット60%・許容損失（1日4%・トータル6%）の狭さ・返金なしというコストを承知の上で選ぶこと。即時型は「手軽さの対価」をどこかで払う構造です。これは特定の業者に限った話ではなく、即時資金型ジャンル全体の傾向なので、[即時資金型プロップ徹底比較](/guide/propfirm-instant/) で相場観を持ってから判断してください。

### 資金規模を上げたい実力者 → TheStandard $200k

すでに$100kクラスで安定して目標達成・運用できる実力があり、同じ手法をより大きな資金で回したい人は **TheStandard $200k**。率はすべて$100kと同じなので、勝ちパターンを持っている人ほどスケールメリットを取りやすい設計です。逆に、$100kでまだ一度も完走していない段階で飛びつくのは避けましょう。

### EA・自動売買を使いたい人 → TheStandard推奨（全プランEA可）

Fintokeiは全プランでEA（自動売買）が許可されています。EA運用なら、スプリット80%で長期的に回収しやすい **TheStandard** が基本線です。EAの選定・運用の注意点は [プロップファームでのEA活用](/guide/propfirm-ea/) を参照してください。なおコピートレードは全プランで不可なので、EAとコピーを混同しないよう注意が必要です。

### スキャルピング中心の人 → 許容損失の差に注意

Fintokeiはスキャルピング可ですが、TheInstantは1日最大損失4%とTheStandard（5%）より狭く設定されています。回転数が多くドローダウンが膨らみやすいスキャルパーは、許容損失に余裕のあるTheStandardのほうが運用しやすい場面が多いでしょう。スキャル運用の全体像は [プロップファームのスキャルピング](/guide/propfirm-scalping/) で確認できます。

### 日本語サポートを重視する人 → 全プランで強み

英語に不安があり、規約やサポートを母国語で完結させたい人にとっては、プラン以前にFintokeiという選択自体が強みです。サイト・規約・サポートまで日本語対応しているため、利益目標やドローダウンの細かい条件を「なんとなく」ではなく正確に理解したうえで取引できます。これは合否や手取りに直結する地味で大きなメリットです。同じく日本語で完結できる業者を比較したい方は [日本語対応プロップファーム](/guide/propfirm-japanese/) を参照してください。

他社プランと横並びで比較したい場合は [プロップファーム条件比較](/guide/propfirm-hikaku/) もあわせてご覧ください。Fintokeiの口座開設や評判のリアルは [Fintokeiの評判・口コミ](/guide/fintokei-hyoban/)、業者ページは [Fintokei詳細ページ](/prop/fintokei/) にまとめています。

> **【宮城ガイの監修コメント】** プラン選びで一番多い失敗は「口座サイズを大きく見せたくて背伸びする」こと。$200kの口座に憧れる気持ちは分かりますが、許容損失も倍になる以上、メンタルへの負荷も倍です。まずは$100kで「ルールの中で勝つ」感覚を体に入れる。資金規模は実力がついてから後から上げられます。順番を間違えないことが、結局いちばんの近道です。

## プラン選びの落とし穴・注意点

数字だけ見て申し込むと、後で「こんなはずでは」となりがちなポイントを整理します。

**1. 受験料の安さでTheInstantに飛びつかない**

TheInstant $50k（$549）はTheStandard $100k（$599）とほぼ同じ受験料に見えますが、口座サイズが半分・スプリットが60%・返金なしです。「受験料が同じくらいなら手軽なほうで」と即決すると、合格後の手取りで差がつきます。入口コストではなく、合格後のリターン構造で比べましょう。返金制度の一般論は [受験料返金の仕組み](/guide/propfirm-refund/) が参考になります。

**2. スプリット60%と80%の差を軽視しない**

同じ$10,000の利益を出しても、80%なら手取り$8,000、60%なら$6,000。差は$2,000です。利益が積み上がるほどこの差は広がります。手軽さを取るか手取りを取るか、自分の優先順位を明確にしてください。

**3. ドローダウンの「率」と「金額」を両方で把握する**

$200kは率が$100kと同じでも、損失の許容額（金額ベース）が倍になります。金額で見ると数字が大きく見えて気が緩みがちですが、口座に対する率は同じなので、運用の厳しさは変わりません。むしろ金額が大きい分、1トレードの値動きが手取りに与える影響も大きくなります。ドローダウンの考え方は [プロップファームのドローダウン解説](/guide/propfirm-drawdown/) で再確認しておきましょう。

**4. コピートレード不可を見落とさない**

EA・指標トレード・スキャル・両建て・週末保有はすべて可ですが、コピートレードは全プラン不可です。コピー運用を前提に考えていた人は、Fintokeiでは別の手法に切り替える必要があります。禁止事項の全体像は [プロップファームの禁止事項](/guide/propfirm-kinshi/) で確認してください。

**5. クーポンの真偽に注意**

Fintokeiには現在、常時公開されている固定の割引コードはありません。季節キャンペーンが時々開催される形です。SNSや非公式サイトで「限定クーポン」を名乗るものを見かけても、出所が不確かなコードは安易に使わないこと。最新の正規キャンペーン情報は [クーポン一覧ページ](/coupon/) で随時更新しています。

**6. 受験料は税務上の扱いも意識する**

受験料や利益分配は、確定申告の際にコスト・所得として扱いが関わってきます。本格的に運用するなら早めに [プロップファームと税金](/guide/propfirm-zeikin/) を確認し、記録を残しておくと後で慌てずに済みます。

**7. 「期限なし」を言い訳にして手を広げすぎない**

Fintokeiの3プランは期限なしで進められます。これは大きな利点ですが、裏を返せば「いつでも取り返せる」という油断にもつながりがちです。時間制限がないからとポジションを放置したり、根拠の薄いトレードを重ねたりすれば、結局はトータルのドローダウンに引っかかります。期限がないのはあくまで「焦らず規律を保つための余白」であって、「いくらでもミスを許す保証」ではありません。ルールベースで淡々と積み上げる姿勢が、どのプランでも合否を分けます。

**8. プラットフォームを先に決めておく**

Fintokeiは全プランでMT4/MT5/DXtradeから選べますが、普段使い慣れたツールがあるなら、それに合わせてプランの運用イメージを固めておくとスムーズです。特にEAを使う場合はMT4/MT5が前提になります。環境構築のハードルやツールごとの違いは [プロップファームのプラットフォーム比較](/guide/propfirm-platform/) でも整理しています。

## まとめ

Fintokeiのプランは、突き詰めると次の判断軸で選べます。

- **王道で手取りを最大化したい** → TheStandard $100k（受験料$599・スプリット80%・返金あり）
- **最短で試験なしに始めたい** → TheInstant $50k（受験料$549・試験なし・スプリット60%）
- **実力者が資金規模を上げたい** → TheStandard $200k（受験料$1,099・$100kと同条件で倍スケール）

全プランに共通する強みは、期限なし・MT4/MT5/DXtrade対応・EA可・スワップフリー、そして何より完全日本語対応で規約を母国語で精査できることです。一方でコピートレード不可・即時型のスプリット控えめといった注意点もあるため、「受験料の安さ」ではなく「合格後のリターン構造とドローダウン設計が自分のスタイルに合うか」で選ぶのが失敗しないコツです。

まずは [Fintokeiの評判・口コミ](/guide/fintokei-hyoban/) で運営の安心感を確かめ、[チャレンジ攻略のコツ](/guide/propfirm-challenge-tips/) で合格戦略を固めたうえで、自分に合うプランを選んでください。他社と迷う場合は [おすすめプロップファームランキング](/guide/propfirm-osusume/) と [プロップファーム条件比較](/guide/propfirm-hikaku/) を併用すると、Fintokeiの立ち位置がよりクリアになります。
